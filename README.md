## 왜 만들었나요?

학령기 자녀를 둔 맞벌이 부모는 매일 쏟아지는 학교 알림장과 가정통신문을
하나하나 챙겨 볼 시간이 없습니다. 그 사이 준비물, 제출 서류, 학사일정 같은
중요한 정보를 놓치고, 아이는 다음 날 곤란을 겪습니다.

**NoticeTogether**는 길고 복잡한 가정통신문에서 핵심만 빠르게 요약해 보여주고,
준비물·제출서류·기한을 체크리스트로 정리해 부모가 바로 행동할 수 있도록
돕는 서비스입니다.

## 핵심 기능

- 📝 **알림 요약** — 학교·복지관 알림장의 핵심 내용을 자동으로 요약
- ✅ **준비물 체크리스트** — 준비물, 제출 서류, 기한을 놓치지 않도록 정리
- ⏰ **일정 관리** — 학사일정과 마감일을 한눈에 확인
